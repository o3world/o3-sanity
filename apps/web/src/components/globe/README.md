# Reusable O3 globe renderer

`GlobeProvider` supplies the O3 GPU renderer through `OrbitalRendererContext`. Every existing `OrbitalSphere` placement inherits it: homepage and interior heroes, closing CTA bands, and quote decorations. The shared UI component owns the seeded geometry, palette, layout, motion setting, and SVG fallback. The app owns vgpu, the sky, and GPU lifecycle; other apps keep the SVG renderer.

The provider is enabled in development and in preview/staging builds when `O3_SPATIAL_GLOBE=1`. The web deployment workflow supplies that flag; Turbo includes it in the cache key. Next bakes the resulting boolean into the build so request-time rendering uses the same choice as prerendered pages. `VERCEL_ENV=production` always disables the scene. The production promotion workflow is unchanged. The approved appearance is saved at `4530b605` before extraction.

The enabled site provider starts loading the separate renderer chunk immediately on mount and warms the globe shaders before a canvas is needed. `globe-runtime.ts` owns one GPU device and its pipeline cache for the provider's lifetime, including client-side page navigation. Each placement borrows independent draw objects from a reusable pool; the pool grows only to the concurrent high-water mark. Unmounting a globe returns its draws and disposes its surface and listeners without destroying the shared device. Provider teardown destroys the device; failed startup or device loss clears the cache so a later placement can retry. Device loss restores SVG fallbacks for active globes.

Placements prepare within 800px of the viewport, but intersection and document visibility still pause frame submission when offscreen. React owns each canvas through a portal. Every placement reveals over 200ms after its first frame. The homepage paints a seeded sky from server HTML immediately. A small inline Canvas2D bootstrap projects those same seeds at the initial camera position before hydration; it shares the GPU camera's depth response and clock, crossfades into the first completed GPU frame, then stops and releases its buffer. It redraws only when its size or camera position changes. The SVG remains the fallback when JavaScript or WebGPU is unavailable. The shared vertical camera descent plays once when the document opens on Home; logo links, browser history, and first arrivals from an interior page show the camera at rest while ambient motion continues. A full Home reload starts a new entrance. On that initial load, the scene establishes its own clock before hydration on the hero element’s `__o3SceneStart` property, without changing React-owned HTML attributes. The globe starts rising at 160ms, takes 2047.5ms to rise and 750ms to return, and settles at 2957.5ms. Both sky renderers use the same scene clock: stars rise from the start through the complete entrance without overshooting or rebounding. GPU readiness catches up to the current scene time rather than restarting it. The nav and text keep a separate CSS stagger, so text edits and delays cannot postpone the globe. The spatial homepage text starts at 300ms, 400ms, 500ms, and 600ms. Each element eases into place over 600ms without overshoot, so the headline lines settle at 900ms and 1000ms, the paragraph at 1100ms, and the button at 1200ms. Travel remains 0.3em for headlines and 18px for supporting copy and the button. Internal Home arrivals show this content immediately. The copy stays fully opaque throughout its native scroll exit. The desktop nav travels 18px; below 1024px it fades without vertical travel. The globe's mobile travel remains 55.2px and its overshoot remains capped at 6px (3% of travel on smaller globes). Reduced motion, still mode, restored scroll positions, and route arrivals retain their existing static entrance behavior. The SVG remains the fallback when GPU rendering is unavailable.

Each placement renders into its own color and depth textures before compositing onto the canvas. Solid planet bodies paint before rails, and both use per-fragment depth so crossings cannot erase planets or ignore a rail's local depth. Near-side hero rails are opaque while retaining their apparent brightness. Hero spheres receive a quiet neutral fill and red light from the glow ring; that light shares the subtle heat shimmer's radius. The shimmer and light source follow the camera in the SVG bloom's plane, keeping all three aligned during entrance. Still and reduced-motion modes omit the shimmer. Placement cleanup releases both textures along with its borrowed draws.

The homepage opener uses the full starfield. Dark interior heroes with globes and closing CTA bands use a quieter, distant-only field with slower motion and no shooting stars. Light heroes and quote decorations remain globe-only and allocate neither stars, shooting stars, nor rail masks. Hero presets inherit the approved compact SVG glow; background and line presets retain their palette and opacity. Dot illumination is red only for the hero preset. Star masks erase sky pixels before translucent rails are painted.
