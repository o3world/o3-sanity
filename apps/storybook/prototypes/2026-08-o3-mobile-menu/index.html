What this takes from Facebook, and what it refuses

The brief was to model a modern mobile menu on Facebook’s. Facebook solves a different problem — dozens of destinations, returning users, utility density — so the patterns transfer and the density does not.

Taken

  • Full-screen overlay, not a narrow drawer. At 402px a drawer wastes the width it just took.
  • The trigger becomes the close. The control never moves; the bars rotate into an X in place.
  • Primary action pinned to the bottom, in the thumb arc — where Facebook keeps account actions.
  • Utility links demoted to a quiet 12px row beneath it.

Refused

  • Row density. Facebook sets ~17px rows because it has forty destinations. O3 has five, so they get the 40px headline step and read as editorial, not as a settings list.
  • An icon per row. Icons here are decorative (ADR 0009); a glyph beside “About” would carry nothing.
  • Search, avatars, badges. No search exists on this site. Importing the affordance would promise one.

Taken from O3, not Facebook

  • The panel sits on Gradient/Red/1 — the design’s signature ember, and how the red appears without a flat fill.
  • Square corners, Figtree 400, and the 20px gutter, straight from the 402 frames.
  • Rules at on-ink-line, the same 20% white as the footer’s orbital arc.

Three things this proposal decides that the frames never did

The nav carries all five items plus “Let’s talk”. Taken from the NavBar component (1710:2271), which is the source of record for nav copy — note the display label is Insights while the route is /perspectives, per #33’s correction. Live’s URL is still undecided on #33, so it is shown unresolved rather than invented.

The staggered rise is new motion. Figma frames are static and #33’s motion question is open, so this is a proposal, not a reading. It uses the house easing and collapses entirely under prefers-reduced-motion.

The control needs an accessible name. Every other icon in the design sits beside a label and is decorative; this one is icon-only, so it carries aria-label, aria-expanded and aria-controls — flagged in ADR 0009 and implemented here.

Type is set in the theme’s own declared fallback ('Helvetica Neue', Arial) rather than Figtree — the artifact sandbox blocks font CDNs, and a silent substitution is worse than a stated one. Sizes, weights and spacing are the real values, so proportion is accurate and letterforms are not.
