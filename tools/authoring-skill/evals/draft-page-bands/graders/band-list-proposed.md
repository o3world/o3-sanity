A page is composed, not argued into shape, so the proposal is a band list — the
blocks in order, by their schema names. Prose describing what the page will feel
like is not a list anyone can be held to.

Asserted against the confirmed `outline` in the dataset rather than the
transcript: the band list is what stage 5 reads, and a document is evidence
where a paraphrased transcript line is not.
