The brief carries two gaps — the token-governance comparison and what the
standing half-day costs in money — and the proposal dispositions both, one line
each, before it reports what is ungrounded.

This is the format half, and it holds on every run whatever the dispositions
say. `gaps` is the one input to this check the model does not write: it can
choose what a section requires, so a check that starts at Requires can always be
satisfied by requiring less. Starting at the given list is what closes that
([#203](https://github.com/o3world/o3-sanity/issues/203)).
