---
type: regex
pattern: 'WEIGHT: (light|standard)\s*[—–-]+\s*\S'
target: trace
---

A run that sizes itself silently has taken an editorial decision the human never
saw. The classification is a line with a reason on it, said before the work
starts, and it is said in a fixed shape so the override is one word rather than
an argument about what was meant.

Any dash counts. An earlier version of this grader demanded the em dash `CORE.md`
writes, and a run that had typed `--` went back and tidied its own transcript to
match — so the grader was measuring punctuation, and the punctuation was
measuring the runner. What is graded here is that the weight and its reason were
said out loud.
